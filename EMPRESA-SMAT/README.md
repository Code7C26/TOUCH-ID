# EMPRESA-SMAT · documentos de la empresa

**SMAT** es una división de **TOUCH**; su producto es **DROID-E3D** (robot + web). Acá se arma la empresa desde cero.
Socios: **Toro** y **Morena**. Cada socio escribe su parte; Claude ayuda a redactar solo lo que se le pida y no decide por la empresa.

## Cómo trabajamos
1. Cada documento tiene un Issue `smat:empresa` con su responsable.
2. Se escribe en la rama `SMAT-empresa` (o una rama propia) y se abre un Pull Request a `main`.
3. **Lo revisa el otro socio** y lo mergea. Las decisiones de los dos van en un Issue `smat:decision`.
4. Al aprobarse, se cambia el estado acá. Estados: `plantilla` → `borrador` → `en revisión` → `aprobado`.
5. Las preguntas guía están en cursiva dentro de cada plantilla: se responden y se borran.

## Orden recomendado
1. **Identidad** y **Marca** primero: la web pública y los colores dependen de ellos.
2. **Organización** y **Acuerdo de socios**: conviene definirlos pronto.
3. **Negocio** y **Finanzas**: de ahí salen los precios de la página «Planes».
4. **Comercial**, **Legal**, **FODA** y **Presentaciones** al final.

> Los textos de la web pública (misión, precios, cómo funciona) se toman de estos documentos. Mientras no estén aprobados, la web usa textos provisorios marcados `TODO`.
